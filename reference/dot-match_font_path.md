# Resolve a font family name to a font file path (cached)

Resolve a font family name to a font file path (cached)

## Usage

``` r
.match_font_path(font_name)
```

## Arguments

- font_name:

  A font family name, e.g. "Proxima Nova".

## Value

A length-1 character path, or NA_character\_ if not resolvable.
